## Структура файлов товародвижения

**Файлы товародвижения** хранятся по пути:  
`/invent_trans/invent_trans_YYYY_MM.csv`  
Формат: CSV, разделитель — точка с запятой (`;`).

Поля файла:
* `item_id` — идентификатор товара;
* `location_id` — идентификатор подразделения;
* `trans_date` — дата в формате `YYYY-MM-DD`;
* `qty` — количество (разделитель целой и дробной части — точка `.`);
* `cost_amount` — себестоимость (разделитель целой и дробной части — точка `.`).

**Важно:** отрицательные значения `qty` означают расходную операцию, положительные — приходную.

## Структура файлов товарных остатков

**Файлы остатков** хранятся по пути:  
`/stock/stock_YYYY_MM_DD.csv`  
Формат: CSV, разделитель — точка с запятой (`;`).

Поля файла:
* `item_id` — идентификатор товара;
* `location_id` — идентификатор подразделения;
* `trans_date` — дата в формате `YYYY-MM-DD`;
* `qty` — количество исходящего (на конец дня) остатка на дату `trans_date` (разделитель целой и дробной части — точка `.`);
* `cost_amount` — себестоимость исходящего (на конец дня) остатка на дату `trans_date` (разделитель целой и дробной части — точка `.`).

## Задача

Необходимо на основании помесячных данных о товародвижениях и начального остатка реализовать расчёт подневных остатков товаров. Результаты нужно записать в CSV-файлы формата `stock_YYYY_MM_DD.csv`.

## Требуемые результаты

Необходимо предоставить:
* скрипт на Python (`*.py`) с реализацией расчёта;
* файл `stock_2025_07_31.csv` с данными об остатках на 31.07.2025.
